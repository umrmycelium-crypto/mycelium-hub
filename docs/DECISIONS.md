# Architecture Decisions

## AD-001
Decision: Use Jellyfin instead of Plex.
Reason: Open source, no licensing restrictions, better self-hosting alignment.
Date: 2026-06-04
Status: Accepted

## AD-002
Decision: Use Gemini CLI for development assistance.
Reason: Deep repository analysis capabilities and structured tool use for codebase management.
Date: 2026-06-04
Status: Accepted

## AD-003
Decision: Use Ollama for local inference.
Reason: Privacy-preserving, offline-capable reasoning for intent routing and local agents.
Date: 2026-06-04
Status: Accepted

## AD-004
Decision: Use Obsidian as primary knowledge store.
Reason: Markdown-based, local-first long-term memory with robust linking for research and history.
Date: 2026-06-04
Status: Accepted

## AD-005
Decision: Use Jellyfin as primary media server.
Reason: High performance, open source, and seamless integration with the local network.
Date: 2026-06-04
Status: Accepted

## AD-006
Decision: Use Jellyseerr instead of Overseerr.
Reason: Native Jellyfin support; Overseerr requires Plex for library indexing.
Date: 2026-06-04
Status: Accepted
